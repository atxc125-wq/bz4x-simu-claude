# BZ4X Trip Optimizer Pro 🚙⚡

トヨタ bZ4X および スバル ソルテラ 専用に開発された、超高精度なEVルート＆充電シミュレーターです。
既存のナビアプリでは考慮されない「外気温によるヒーター消費」「標高差による電費変動」「150kW急速充電器における15分以降の熱ダレ（出力制限）」を完全にシミュレートし、最もリアルで実用的な長距離ドライブ計画を提供します。

## 🌟 主な機能
- **高精度SOC予測:** 標高データ（Google Elevation API）、気象データ（気温・風速）、速度域（高速/下道）を組み合わせた物理演算。
- **bZ4X専用充電カーブ:** SOC帯ごとの受入能力と、150kW機特有の「15分熱ダレロジック」を完全再現。
- **プレコンディショニング機能:** 到着前のバッテリー昇温による電力消費と、充電開始時の受入性能向上をシミュレート。
- **緊急レスキュー検索:** 電欠（SOC 0%）予測時に、ルート周辺の充電器を自動でサジェスト。

## 🏗️ システム・アーキテクチャ（AIへのコンテキスト）

本アプリは、静的ホスティング（GitHub Pages 等）で動作する完全なフロントエンドアプリですが、裏側では **GitHub Actions を用いた「二段構えの充電器データ自動収集パイプライン」** が稼働しています。

今後の開発や機能追加を行うAI（Claude等）は、以下のデータ構造を必ず把握した上でコードの修正を行ってください。

### 🔋 充電器データベースの構造（ハイブリッド方式）

充電器データは以下の2つのスクリプトによって独立して生成され、HTMLの読み込み時にフロントエンド側で動的にマージされます。

#### 1. V1データ（主電源・絶対的正義）
- **スクリプト:** `build_chargers.py`
- **出力先:** `chargers_data.js` (`const CHARGER_DATA`)
- **役割:** アウディ等の「本物の水冷150kW機（FLASH）」の公式サイトや、高速道路のSA/PA（eMPネットワーク）を直接スクレイピングして構築される、**最も信頼性の高い基盤データ**です。
- **特徴:** このリストに登録された150kW機は `type: "flash"` として扱われ、シミュレーター上で「熱ダレしない無制限のフルパワー充電」として計算されます。

#### 2. V2データ（補助電源・絨毯爆撃）
- **スクリプト:** `build_chargers_v2.py`
- **出力先:** `chargers_v2_data.js` (`const CHARGER_V2_DATA`)
- **役割:** Googleの「New Places API」を使用し、V1から漏れている街中の新しいディーラー（トヨタ、日産等）や商業施設（オートバックス、道の駅）の **90kW〜150kW級の超高出力機** を絨毯爆撃で拾ってきます。
- **特徴:** bZ4Xの仕様上、ポルシェ等以外の150kW機は熱ダレするため、V2で取得したスポットは出力が150kWであっても全て `type: "normal"`（熱ダレあり）として強制設定されます。
- **重複排除ロジック:** 実行時、V1データを読み込み、**半径150m以内にV1のピンが存在する場合は「V1（FLASH/SAPA）優先」としてV2のデータを破棄**します。

#### 3. フロントエンドでの統合
`index.html` の `<head>` にて上記2つのJSファイルを読み込み、スクリプトの冒頭で以下の処理を行い統合しています。
既存の検索ロジックはすべて統合後の `CHARGER_DATA` 配列を参照します。
```javascript
if (typeof CHARGER_V2_DATA !== 'undefined') {
  CHARGER_DATA.push(...CHARGER_V2_DATA);
}
